# Advertisement Viewability Prediction

## Overview
This academic project explores machine-learning approaches to predicting advertisement viewability using a dataset of 500 real-world advertisements.

## Methods
The project investigated and compared:
- Naive Bayes
- Generalized Learning Vector Quantization (GLVQ)
- Support Vector Machine (SVM)
- Artificial Neural Network (ANN)

Feature selection was explored using Recursive Feature Elimination (RFE). Evaluation used stratified k-fold cross-validation and metrics including precision, recall, and F1-score.

## My contribution
I worked on developing and evaluating the machine-learning approaches, applying feature-selection and cross-validation procedures, and comparing model performance using classification metrics.
